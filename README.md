# Alura Store - Análisis de desempeño de tiendas

## Descripción
Este proyecto analiza el desempeño de cuatro tiendas de la cadena Alura Store con el objetivo de identificar cuál presenta menor rendimiento y recomendar su venta.

## Tecnologías utilizadas
- Python
- Pandas
- Matplotlib
- Google Colab

## Análisis realizados
- Ingresos por tienda
- Ventas por categoría
- Calificación promedio de clientes
- Productos más y menos vendidos
- Costo promedio de envío
- Visualización de datos

## Resultado
El análisis muestra que la **Tienda 4 presenta el menor desempeño general**, por lo que se recomienda su venta.
